# terrain-stereo

国土地理院の実際の標高データから、日本地図で選んだ場所の地形を3D表示するWebアプリです。通常3Dに加え、平行法・交差法・赤シアンアナグリフで立体視できます。

地形ビューの「共有」から場所・視点・表示設定をリンクで共有できます。リンクを開くと、同じ地点とカメラ、表示モード、画質、表面、陰影、等高線などを読み込みます。

トップページの「アプリの使い方を見る」から、場所選び、3D操作、立体視、表面の切替、等高線、断面図、遊覧飛行、共有までを順番に確認できます。案内中は対象の画面部分を強調表示し、いつでも閉じられます。

## 見どころ観察と等高線間隔（0.28.0）

代表6名所（青ヶ島・秋吉台・黒部峡谷・阿蘇・喜界島・南大東島）に10の見どころを追加。名所を表示した後、解説の「見どころへ近づく」で選び「この見どころを見る」を押します。必要なDEMを読み込み、「名所全体へ戻る」で全体に戻れます。地形／地質切替は見どころと手動設定を保ちます。

等高線は10・20・50・100・200mから選択。通常起動は従来の100m・OFF、名所訪問ではおすすめ間隔を設定します。間隔変更に通信は不要です。細かい等高線も既存DEMの補間であり、測量精度を増やすものではありません。

[第2段階の設計・API調査・iPhone Safari確認手順](docs/OBSERVATION_STAGE2.md)、[実DEMのスクリーンショットと検証](docs/OBSERVATION_STAGE2_VERIFICATION.md)。

## 地形と地質を結ぶミニツアー（0.29.0）

秋吉台・青ヶ島・糸魚川周辺の名所ガイドから、地形を見て地質図と比べる短い対話式ツアーを開始できます。見どころへの移動、凡例の表示、「戻る」「終了」を既存機能と連携しています。[内容・Chromium検証・スクリーンショット](docs/LEARNING_TOUR_PHASE3.md)。

## 日本の地形・地質名所ガイド（0.27.0）

「地形・地質の名所を探す」で、既存5地点と新規12地点を種類・地域から選べます。概要を読んで「この場所を見る」を押すと、名所に合わせた範囲・高さ・表面・視点で表示します。「地形を楽しむ」「地質を学ぶ」は現在の視点・範囲・高さなどを保ち、表面と解説を切り替えます。解説の資料と表示の限界も確認できます。共有リンクと通常の初期表示にはおすすめを自動適用しません。

名所データは `js/landmarks.js`、UIは `js/landmark-guide.js`、取得した地形に合わせるカメラ調整は `js/landmark-camera.js`。設計・地点ごとの表示範囲・今後の候補は [名所ガイドの設計](docs/LANDMARK_GUIDE.md) を参照してください。[ブラウザ検証結果とスクリーンショット](docs/LANDMARK_VERIFICATION.md)も公開しています。

新しいブラウザ検証は `python tests/landmarks.browser.py`。国土地理院の実DEMで17地点とスマホ縦横の主要地点を確認し、地質図の実通信とテスト用画像のUI確認は区別します。地質図に失敗すると標高の色で表示し、失敗案内を表示します。既存の地図からの自由選択、凡例・地質地点情報、体験型ツアーを再利用します。

## 体験型機能紹介ツアー

説明する設定をアプリ本来のイベント経由で切り替え、3Dカメラの旋回・接近、高さ倍率と照明のアニメーション、地形表面と立体視の実切替、断面図の2点選択、富士山への移動、遊覧飛行を実演します。「次へ」「戻る」「自動で進む」「一時停止」で操作でき、終了時は開始前の地形、カメラ、表示設定、地図位置、断面図の状態へ戻します。画像やDEMを取得できない場面は、再試行と状態表示を出します。

スマートフォンでは、実演中の操作欄を元のイベントと状態を保ったまま専用枠へ移し、終了時に元の位置へ戻します。縦画面は3D表示・操作欄・説明を上下に、横画面は3D表示と操作・説明を左右に配置します。

Chromium / Playwright のエンドツーエンド確認は `python tests/tour.browser.py` で実行します。GSI の標高・地図・航空写真タイルを使ってPCとiPhone相当の縦画面・横画面で全10場面を実行します。スマートフォンでは実演中に変わる各操作対象の画面内表示、説明・3D表示との重なり、終了後の操作欄の復帰も確認します。地質図はテスト画像を使い、実機Safariは未確認です。スクリーンショットは `/codex/browser/projectless/0001-3d/output/terrain-tour/` に保存します。

## 起動

Python 3 があれば、リポジトリで次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。ビルドや `npm install` は不要です。JavaScript の ES Modules を使うため、HTML ファイルを直接開く `file://` ではなく HTTP サーバーを使います。

iPhone からは同じ Wi-Fi 上の PC の `http://<PCのLAN内IP>:8000` にアクセスできます。PC のファイアウォールで接続を許可してください。外部公開する場合は静的ファイル一式を HTTPS 対応のホスティングに配置できます。

## GitHub Pagesで公開する

[リポジトリの Pages 設定](https://github.com/enou123/terrain-stereo/settings/pages)で、Source を **Deploy from a branch**、Branch を **main**、フォルダを **/ (root)** に設定して Save を押します。ルートの `.nojekyll` により、静的ファイルをそのまま配信します。

GitHub の公開処理が成功すると、`https://enou123.github.io/terrain-stereo/` を iPhone の Safari から開けます。初回の公開には数分かかることがあります。公開完了は Pages 設定画面または Actions の `pages build and deployment` で確認してください。

必要な環境は、WebGL・ES Modules・Pointer Events・ResizeObserver・createImageBitmap・AbortSignal.timeout に対応した現行 Chrome / Edge / Firefox / Safari と、国土地理院へのインターネット接続です。APIキー・有料サービス・外部ライブラリ・CDN・外部フォント配信は使用しません。フォントは端末にインストールされた `BIZ UDPGothic`、`BIZ UDGothic` を優先し、なければシステムフォントに切り替えます。

## 場所を選ぶ

地図をドラッグ（タッチは1本指）して、中央の＋を見たい場所に合わせます。ホイール・2本指ピンチ・＋/−ボタンで拡大縮小し、「ここを立体表示」を押すとその地点の標高を取得して地形に移動します。地図にフォーカスすると矢印キー・＋/−でも操作できます。石鎚山・富士山・阿蘇山・大雪山・屋久島を含む17地点は「地形・地質の名所を探す」で選べます。選ぶだけではDEMを取得せず、概要を読んで「この場所を見る」でおすすめを適用します。「ここを立体表示」は現在の地図の範囲と利用者の表示設定を使います。

地図の中心は日本周辺（北緯20〜46度、東経122〜154度）で自由に選択できます。枠は3Dに表示する範囲です。地図を縮小すると範囲が広がり、拡大すると狭くなります。地図の縮尺を1段階変えると範囲は約2倍・半分になります。選択地点の下に距離を表示します。標高データの対応範囲に合わせて、最小約2.5〜3.5km、最大約650〜880km四方に制限します。初期表示は従来と同じ約12.2km四方です。海上など標高がない範囲は表示できない場合があります。地図を動かすだけでは標高を取得しません。画面上の「立体表示中の場所」は最後に取得成功した地点を示し、地図で選び直した地点とは区別します。地点変更時は視点をリセットし、表示モード・立体感・高さ強調は維持します。

標高は最大24タイルをメモリ内で再利用します（永続保存なし）。同じ場所の再表示や近くへの移動では通信量を抑えられます。読み込み中は表示ボタンを無効化し、失敗時は要求した地点を「もう一度読み込む」で再試行します。

## 操作

| 操作 | PC | タッチ |
| --- | --- | --- |
| 回転・俯角変更 | 左ドラッグ | 1本指でドラッグ |
| ズーム | ホイール | 2本指でピンチ |
| 地形の移動 | Shift＋左ドラッグ、または中ボタンドラッグ | 2本指でドラッグ |
| 視点リセット | 「初期の視点に戻す」 | 同左 |

地形にフォーカスすると、矢印キーで回転・俯角変更、`+` / `-` でズーム、`R` で視点リセットもできます。高さ強調は 0.5〜4.0 倍で変更でき、初期値は 1.5 倍です。1.0 倍が水平距離に対する実際の高さ比率です。視点リセットは高さ強調の設定を維持します。

## 立体視

「表示モード」で切り替えます。回転・ズーム・移動と高さ強調は、すべてのモードで共通です。

| モード | 見方 |
| --- | --- |
| 通常3D | 1つの地形を表示。 |
| 平行法 | 左に左眼用、右に右眼用。遠くを見るように視線を平行にし、中央で重なる地形を見ます。 |
| 交差法 | 左に右眼用、右に左眼用。視線を交差させ、中央で重なる地形を見ます。 |
| 赤シアン | 左眼が赤、右眼がシアンの眼鏡を使用。標高色を白黒に変換し、赤・緑青のチャンネルへ合成します。 |

立体感は0〜2（初期値1）で調整できます。0では左右画像の視差がなくなります。見づらいときは値を下げてください。視点リセットは表示モード・立体感・高さ強調の設定を維持します。平行法・交差法は画面を左右に分け、それぞれの縦横比に合わせて表示範囲を調整します。

左右のカメラは平行に配置し、非対称の透視投影で注視点を画面面に合わせます。両眼間隔はカメラから注視点までの距離の2.5% × 立体感です。注視点より手前と奥では視差の向きが逆になり、カメラを内向きに傾けることで生じる上下のずれを避けます。

## 利用データと処理

- 出典：[国土地理院・地理院タイル（標高タイル）](https://maps.gsi.go.jp/development/ichiran.html#dem)
- データ：標高タイル `dem`（基盤地図情報の10mメッシュ等をもとにした全国の標高データ）、テキスト形式、ズーム6〜14。
- URL：`https://cyberjapandata.gsi.go.jp/xyz/dem/{z}/{x}/{y}.txt`
- 背景地図：国土地理院の標準地図 `std/{z}/{x}/{y}.png`、ズーム4〜13。
- タイルは 256×256 のCSV形式で、値はメートル単位の標高、`e` は欠測値です。
- 初期地点は北緯33.767度・東経133.115度（石鎚山周辺）。地図の選択地点を中心に、必要なタイルだけを読み込み、中心の384×384ピクセルの範囲を2ピクセル間隔でサンプリングします。
- 表示範囲は初期地点で約12.2km四方（選択地点の緯度により変化）、193×193頂点、最大73,728三角形。初期表示の点間隔は約64mで、縮尺とともに変わります。元データの10mメッシュすべてを描画するものではありません。
- 水平距離は中心緯度での Web Mercator の縮尺から近似計算します。X は東、Y は標高、Z は南で、距離単位は km です。
- 標高で色分けし、メッシュの法線から斜面の陰影を描画します。高さ倍率の変更時は頂点と法線を再生成します。
- 欠測値を含む三角形は省きます。タイル取得失敗時はエラーと再試行を表示し、代替の架空地形は表示しません。25秒の通信タイムアウトを設けています。
- データはブラウザから直接取得し、サーバー側の代理取得やローカルへの同梱は行いません。

画面内にも「国土地理院の標高・標準地図を加工して作成」と出典を記載しています。[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)も参照してください。この表示は地形を楽しむための簡易ビューアで、測量や登山経路の判断用ではありません。

## 更新時のキャッシュ対策

公開時は `package.json` の `version` を更新し、`index.html` のCSS・JavaScript参照と `js/` 内のすべてのモジュールimportに同じ `?v=バージョン` を付けます。入口だけでなく依存モジュールまで更新することで、古いブラウザキャッシュと新しいHTMLの混在を防ぎます。`npm test` は参照先の存在とバージョンの一致を検証します。

## 今後の拡張

2. 3D表示から周辺へ移動、地点のURL共有。
3. 地形に追従する方位・山名・スケールの表示。
4. iPhone実機・Safariを含む端末別の描画性能と操作検証。

機能を追加する際は、表示モードを描画側に、地点とデータ解像度を標高取得側に追加する構成です。

地図のズーム+1を標高取得のズームに使い、6〜14に制限します。標準は193×193頂点・最大9タイル、高精細は最大385×385頂点・16タイル、最高精細は最大769×769頂点・49タイルです。画質に応じてより細かい標高を取得し、同じ地理的範囲を維持します。取得ズーム14の上限ではサンプリングを細かくし、それ以上は増やしません。広域では粗いデータを使います。地形の最低標高を表示上の基準にして、3Dの全軸を同じ倍率で画面に合わせるため、高さと水平距離の比率は維持されます。広域では山が低く見えます。地図の縮尺変更だけでは取得せず「ここを立体表示」で反映します。

## 画質を選ぶ

「地形の見え方」の「画質 · 地形の細かさ」で標準・高精細・最高精細を選べます。初期設定は標準です。変更すると表示中の地点・範囲を読み直し、視点・表示モード・高さ強調は維持します。新しい地図の中心は「ここを立体表示」で反映します。各画質の実際の標高サンプル間隔をメートルで表示します。最高精細は標準の約16倍の頂点を使うため、スマートフォンでは高精細から試してください。同時取得は最大4件、メモリキャッシュは最大24タイルです。失敗時は以前の地形を保持して再試行できます。

## 観察補助（0.7.0）

ビュー下隅のコンパスは地形の回転・傾きに追従します。Nは北、Eは東、Sは南、Wは西です。平行法・交差法では左右それぞれの左下に眼用ラベルと小さな＋を表示します。＋を重ねることを目印にして左右画像を合わせてください。通常3D・赤シアンでは＋を表示しません。設定項目は増やさず自動で切り替えます。

## 飛行モード（0.17.0）

ビュー上部の「移動」でパッドを表示します。「遊覧飛行 · 約32秒」を押すと、開始位置の周囲を一周するコースを自動で飛び、向きと高度をゆっくり変えて開始位置へ戻ります。途中停止できます。方向ボタンやPCのW/A/S/D、Q/Eを使うと遊覧を止めて手動操作へ切り替わります。手動ではボタンを押すたびに少し移動し、PCは地形にフォーカスしてキーを押している間移動します。＋／−で高度を変更します。現在は読み込み済みの地形範囲内のコースで、地図上の地点は移動しません。

## 標高タイルがない範囲（0.7.1）

高画質で使用する細かなタイルがHTTP 404になる場合は、その範囲だけ同じ位置の広域標高タイルで補完します。補完があれば画質欄に案内を表示します。高画質を選んでも、元のデータがない場所の実際の精細さは上がりません。海など標高値がない部分は埋めず、範囲全体に標高がない場合はその旨を表示します。通信障害やHTTP 503等は補完対象にせず再試行できます。

追加の実データ回帰確認：`python tests/fallback.browser.py`。33.2035°N / 132.1812°E、DEMズーム9の同じ範囲で画質を切り替え、実際の404応答と親タイルを使用します。結果画像はリポジトリ外の`terrain-stereo-preview/surface-coastal/`に保存します。


## 等高線（0.8.0）

設定の「等高線を表示」をONにすると、読み込み済みの地形に実際の標高を10・20・50・100・200 m間隔で示す線（通常起動は100 m）を表示します。初期状態はOFF。高さ強調を変えても同じ標高を示し、4つの表示モードすべてで使用できます。視点リセット、設定開閉、拡大表示、画面回転、地点・画質変更でもON/OFFを保持します。切替による追加の通信はありません。

線は表示中のDEMと三角形内の標高補間に基づきます。画質が粗い場合・広域データで補完した部分では線の細部も粗くなります。海域などの欠損部分には線を描きません。線を識別できないほど遠ざけた場合は薄くし、平らな面全体を等高線として塗りません。線の間隔変更・標高ラベル・地図上への等高線表示は今回の対象外です。

等高線にはWebGL拡張 `OES_standard_derivatives` を使用します。非対応端末ではこの設定を無効にして説明を表示し、従来の3D表示は継続します。

追加の描画回帰確認：`python tests/contours.browser.py`。既知の標高で5種類の間隔の線と中間標高の画素、OFFへの復帰、平坦面、欠損部分、拡張非対応時の描画・UIを検証します。UIと沿岸部の実データ回帰は上記の2つのブラウザテストで確認します。Chromiumでの検証であり、Safari実機検証ではありません。


## 地形表面の切替（0.9.0）

設定の「地形表面」で「標高の色（従来の表示）」と「陰影のみ」を選べます。初期値は従来の表示です。「陰影のみ」は標高に応じた色を外し、斜面の向きによる明暗で尾根や谷を見やすくします。太陽位置は変更せず、既存の固定照明を使います。

4つの表示モード・等高線と併用できます。陰影のみ・赤シアンでは標高色の凡例を隠します。設定開閉・拡大・縦横回転・高さ強調・画質変更・地点変更・視点リセットでも選択を保持します。切替は追加の通信・メッシュ再生成を行いません。航空写真・地質図・画像テクスチャは今回含みません。

### 太陽の向きを変える

「太陽の方位」と「太陽の高さ」で、斜面に当たる光の方向を調整できます。標高色・陰影・地理院地図・航空写真のすべてに反映し、4つの表示モードと等高線にも併用できます。初期値は北西から高度35度で、これまでの照明方向を保ちます。設定はこのブラウザ内に保存し、DEMや画像を追加取得せず、メッシュも再生成しません。これは地形表示の照明調整であり、日時・緯度経度から太陽位置を天文学的に計算する機能ではありません。

### 地形をPNGで保存する

ビュー上部の「PNG」を押すと、現在の3Dキャンバスを画面解像度のPNGにします。iPhoneなどファイル共有に対応するブラウザでは共有シートが開き、「画像を保存」や保存先を選べます。それ以外のブラウザではPNGをダウンロードします。立体視モードは表示中の左右画像または赤シアン画像のまま保存します。方位計や操作表示などキャンバス外のUIは画像に含みません。

描画回帰確認は`python tests/contours.browser.py`にも追加しています。陰影が標高色に依存せず斜面の向きに応じて変わること、全4モードで元の表示に戻せること、両表面で等高線と欠損部分を検証します。結果は`terrain-stereo-preview/surface-shader/`に保存します。

## 地図テクスチャ（0.10.0）

「地形表面」の「地理院地図」で、標準地図を3D地形に重ねます。初期表示は従来の標高色です。画像は選択時だけ読み込み、画質・高さ・視点を変えても同じ地理的位置に重なります。等高線と全立体視モードも併用できます。標準地図に印刷された等高線は、追加の等高線チェックをOFFにしても残ります。

画像は地形の縮尺に合わせたズーム（上限14）から取得し、1024×1024の画像1枚にまとめます。地形の画質とは別の細かさで、文字を拡大しても精細さは増えません。最大16タイル・並列4取得・25秒タイムアウト。現在の範囲の画像1枚だけをメモリで再利用し、地点を変えると置き換えます。失敗時も標高色の地形は操作でき、設定から地図画像だけを再試行できます。

新規回帰：`node --test tests/texture.test.js`、`python tests/texture.browser.py`、`python tests/texture.gpu.browser.py`。実地図の8画面テストと画像は `terrain-stereo-preview/map-texture-phase-1/`、既知配色によるGPU結果は `texture-shader/` に保存します。


## 航空写真（0.11.0）

「地形表面」から「航空写真」を選ぶと、国土地理院のシームレス写真を3D地形に重ねます。撮影時期は地域で異なり、最新の状況とは限りません。地図と同じ画像の細かさ・取得上限で、選択したときだけ読み込みます。全立体視モード・等高線に対応し、赤シアンでは写真を白黒の明るさに変換します。

取得できない範囲や通信失敗では標高色の地形を維持し、「航空写真を再読み込み」で画像だけを再試行できます。地図と写真はそれぞれの種類を確認して描画し、切替中に別種類の古い画像を使いません。画像のメモリキャッシュは合計1枚で、地図と写真を往復すると再取得します。

写真の8画面検証は `TEXTURE_SURFACE=photo python tests/texture.browser.py`、地図の回帰は `python tests/texture.browser.py`。404時・遅れて届く画像・地図と写真の往復は `python tests/layer.browser.py`、向き・欠損・GPU解放は `python tests/texture.gpu.browser.py` で確認できます。Safari実機の検証とは異なります。

## 地形断面図（0.12.0）

設定の「地形断面図」→「2点を選ぶ」で、地形の始点Aと終点Bをタップ／クリックすると、間の標高グラフを表示します。選択中もドラッグ・2本指で視点を調整でき、「中止」やEscapeでやめられます。キーボードではEnterで画面中央を指定し、矢印で回転して2点目を選びます。左右表示では左画像の中央がEnterの指定位置です。

縦軸は高さ強調前の実標高、横軸はAからの水平距離です。表示中のDEMを補間した断面であり、画質や広域データ補完によって精度が異なります。標高データのない区間は空白になります。地表沿いの距離・傾斜を測る機能ではありません。

平行法・交差法では左右どちらの画像からでも選択できます。赤シアンの選択基準は中央カメラです。A・Bマークは回転に追従する画面上の補助表示で、地形に隠れた地点でも見える場合があります。高さ・回転・表面・表示モードで断面を保持し、画質変更では再計算、地点・範囲変更ではクリアします。設定を閉じれば横画面でも地形を大きく操作できます。

断面計算は初回操作時に読み込み、追加のDEM・画像通信は行いません。新規回帰は `node --test tests/profile.test.js`、`python tests/profile.browser.py`、最高精細は `python tests/profile.ultra.browser.py`。設計と制約は `docs/SECTION-PHASE-1.md`、結果は `VERIFICATION.md`。

## 地質図（0.21.2）

「地形表面」で「地質図」を選ぶと、産総研・地質調査総合センターのシームレス地質図を標高地形に重ねます。地質タイルは選択したときだけ取得し、地形DEM、地理院地図、航空写真とは別の取得元・キャッシュとして扱います。通常3D、立体視、等高線と併用できます。地質図の縮尺・境界には限界があり、現地での判断や専門的な地質調査の代わりにはなりません。

地質図タイルにはGSJ公式APIの `https://gbank.gsj.jp/seamless/v2/api/1.3.1/tiles/{z}/{y}/{x}.png` を使用します。公式仕様に合わせて座標順をY/Xにし、最大ズーム13に制限しています。ブラウザの合成タイル試験はできますが、この開発環境の通信プロキシが外部接続を拒否するため、実配信タイルとiPhone Safari実機の取得は別途確認が必要です。

「地質図」の設定に「この場所の地質を見てみる」を追加しました。表示中の3D範囲だけをGSJの凡例APIへ問い合わせ、地図と同じ色で地質の区分・年代・岩石を示します。タイルと凡例はGSJのオリジナル区分（type=original）で揃えています。level1（6分類）やlevel2（14分類）へまとめず、GSJの公開縮尺上限（ズーム13）で利用できる区分を表示します。詳細は[GSJシームレス地質図V2 API](https://gbank.gsj.jp/seamless/v2/api/1.3.1/)を参照してください。凡例は必要なときだけ取得します。

「見たい場所を探す」地図は、小数ズームで連続的に拡大・縮小します。ホイールとピンチは細かい倍率で動き、＋／−ボタンは半段階ずつ変わります。DEMの画質やデータ取得は従来どおり整数ズームで行い、地図を動かすだけではDEMを再取得しません。

地質図の地形上をクリック／タップすると、その地点をGSJの地点凡例APIで照合し、対応する凡例までスクロールして強調します。設定・凡例が閉じていても自動で開きます。色が同じ区分も凡例記号で区別します。ドラッグ・2本指操作・断面の点選択中には地質選択を行いません。地質図の地形上は通常の矢印カーソルです。

## 都市3D（0.24.0）

地形ビューの「都市3D」で、選択地点を含む日本全国のPLATEAU LOD1建物タイルをCesiumJSで表示します。カメラをドラッグして移動すれば、全国の配信対象地域を続けて探索できます。「東京で試す」は東京駅へ移動し、「選択地へ」は元の選択地点へ戻ります。自治体ごとのデータ有無と詳細度は異なります。

PLATEAU-Terrainの地形とPLATEAU-Orthoの航空写真を重ね、建物が周辺の地表から浮いて見える状態を改善しました。各データは公式配信を直接・必要時に読み込みます。地形や画像が取得できない場合は、他のレイヤーと建物の表示を継続します。CesiumJS 1.117.0は都市画面を開いたときだけCDNから取得します。閉じると描画資源を破棄します。都市ビューの立体視は未対応です。

データ配信仕様：[PLATEAU Terrain](https://docs.plateauview.mlit.go.jp/datasets/terrain/)、[3D Tiles](https://docs.plateauview.mlit.go.jp/datasets/3d-tiles/)、[PLATEAU-Ortho](https://docs.plateauview.mlit.go.jp/datasets/ortho/)。これらのサービスは実験的配信で、建物カバレッジは全国一様ではありません。

描画回帰テスト `python tests/urban.browser.py` は実際のCesiumを使い、合成した3D Tiles建物とテスト用の地図画像を読み込みます。テスト前に `npm pack cesium@1.117.0 --cache /tmp/npm-cache --pack-destination /tmp` を実行し、tarファイルを `/tmp` に展開してください。合成データによる描画確認と配信元の実データ確認は別です。
