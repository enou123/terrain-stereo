# terrain-stereo

国土地理院の実際の標高データから、石鎚山周辺の地形を3D表示するWebアプリです。通常3Dに加え、平行法・交差法・赤シアンアナグリフで立体視できます。

## 起動

Python 3 があれば、リポジトリで次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。ビルドや `npm install` は不要です。JavaScript の ES Modules を使うため、HTML ファイルを直接開く `file://` ではなく HTTP サーバーを使います。

iPhone からは同じ Wi-Fi 上の PC の `http://<PCのLAN内IP>:8000` にアクセスできます。PC のファイアウォールで接続を許可してください。外部公開する場合は静的ファイル一式を HTTPS 対応のホスティングに配置できます。

## GitHub Pagesで公開する

[リポジトリの Pages 設定](https://github.com/enou123/terrain-stereo/settings/pages)で、Source を **Deploy from a branch**、Branch を **main**、フォルダを **/ (root)** に設定して Save を押します。ルートの `.nojekyll` により、静的ファイルをそのまま配信します。

GitHub の公開処理が成功すると、`https://enou123.github.io/terrain-stereo/` を iPhone の Safari から開けます。初回の公開には数分かかることがあります。公開完了は Pages 設定画面または Actions の `pages build and deployment` で確認してください。

必要な環境は、WebGL・ES Modules・Pointer Events・ResizeObserver・AbortSignal.timeout に対応した現行 Chrome / Edge / Firefox / Safari と、国土地理院へのインターネット接続です。APIキー・有料サービス・外部ライブラリ・CDN・外部フォント配信は使用しません。フォントは端末にインストールされた `BIZ UDPGothic`、`BIZ UDGothic` を優先し、なければシステムフォントに切り替えます。

## 操作

| 操作 | PC | タッチ |
| --- | --- | --- |
| 回転・俯角変更 | 左ドラッグ | 1本指でドラッグ |
| ズーム | ホイール | 2本指でピンチ |
| 地形の移動 | Shift＋左ドラッグ | 2本指でドラッグ |
| 視点リセット | 「初期の視点に戻す」 | 同左 |

地形にフォーカスすると、矢印キーで回転・俯角変更、`+` / `-` でズーム、`R` で視点リセットもできます。高さ強調は 0.5〜4.0 倍で変更でき、初期値は 1.5 倍です。1.0 倍が水平距離に対する実際の高さ比率です。視点リセットは高さ強調の設定を維持します。

## 立体視

「表示モード」で切り替えます。回転・ズーム・移動と高さ強調は、すべてのモードで共通です。

| モード | 見方 |
| --- | --- |
| 通常3D | 1つの地形を表示。 |
| 平行法 | 左に左眼用、右に右眼用。遠くを見るように視線を平行にし、中央で重なる地形を見ます。 |
| 交差法 | 左に右眼用、右に左眼用。視線を交差させ、中央で重なる地形を見ます。 |
| 赤シアン | 左眼が赤、右眼がシアンの眼鏡を使用。標高色を白黒に変換し、赤・緑青のチャンネルへ合成します。 |

立体感は0〜2（初期値1）で調整できます。0では左右画像の視差がなくなります。見づらいときは値を下げてください。視点リセットは表示モード・立体感・高さ強調の設定を維持します。平行法・交差法は画面を左右に分け、それぞれの縦横比に合わせて表示範囲を調整します。

左右のカメラは平行に配置し、非対称の透視投影で注視点を画面面に合わせます。両眼間隔はカメラから注視点までの距離の2.5% × 立体感です。注視点より手前と奥では視差の向きが逆になり、カメラを内向きに傾けることで生じる上下のずれを避けます。

## 利用データと処理

- 出典：[国土地理院・地理院タイル（標高タイル）](https://maps.gsi.go.jp/development/ichiran.html#dem)
- データ：標高タイル `dem`（基盤地図情報の10mメッシュ等をもとにした全国の標高データ）、テキスト形式、ズーム12。
- URL：`https://cyberjapandata.gsi.go.jp/xyz/dem/12/{x}/{y}.txt`
- タイルは 256×256 のCSV形式で、値はメートル単位の標高、`e` は欠測値です。
- 中心は北緯33.767度・東経133.115度（石鎚山周辺）。必要なタイルだけを読み込み、中心の384×384ピクセルの範囲を2ピクセル間隔でサンプリングします。
- 表示範囲は約12.2km四方、193×193頂点、最大73,728三角形。表示用の点間隔は約64mで、元データの10mメッシュすべてを描画するものではありません。
- 水平距離は中心緯度での Web Mercator の縮尺から近似計算します。X は東、Y は標高、Z は南で、距離単位は km です。
- 標高で色分けし、メッシュの法線から斜面の陰影を描画します。高さ倍率の変更時は頂点と法線を再生成します。
- 欠測値を含む三角形は省きます。タイル取得失敗時はエラーと再試行を表示し、代替の架空地形は表示しません。25秒の通信タイムアウトを設けています。
- データはブラウザから直接取得し、サーバー側の代理取得やローカルへの同梱は行いません。

画面内にも「国土地理院の標高タイルを加工して作成」と出典を記載しています。[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)も参照してください。この表示は地形を楽しむための簡易ビューアで、測量や登山経路の判断用ではありません。

## ファイル構成

```text
index.html             画面構造・操作UI・出典
styles.css             レスポンシブレイアウト・配色・フォント
js/app.js              読み込み状態・UIと描画の接続
js/elevation.js        座標変換・タイル取得・標高の解析
js/mesh.js             三角形メッシュ・色・法線の生成
js/math.js             透視投影・視点の行列
js/stereo.js           左右の平行カメラ・非対称の透視投影
js/renderer.js         WebGL描画・リサイズ・描画コンテキスト管理
js/controls.js         マウス・タッチ・キーボードの視点操作
tests/terrain.test.js  標高解析・位置・メッシュ・操作のテスト
tests/stereo.test.js   注視点・上下のずれ・視差のテスト
package.json           Node.jsテスト実行用（依存パッケージなし）
```

描画は操作・リサイズ・設定変更時のみ行います。WebGL 1 と16ビットのインデックスを使用し、端末のピクセル比は最大2に抑えています。ページ全体ではスクロールを維持し、地形キャンバス上のみタッチを視点操作に使います。

## テスト

Node.js 18以降で実行できます。

```sh
npm test
# または
node --test tests/*.test.js
```

手動確認では標高タイルの通信成功、3D表示、コンソールエラー、回転・ズーム・移動、高さ倍率、視点リセット、狭い画面、タッチ、通信失敗時の表示を確認します。今回の環境での検証結果は [検証記録](VERIFICATION.md) を参照してください。
