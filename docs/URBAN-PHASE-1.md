# 都市3D 第1段階（0.23.0）

既存の地形描画・立体視を維持し、PLATEAU建物モデル専用のモーダル画面を追加する。

- 国土地理院逆ジオコーダで表示中の場所の自治体コードを取得する。
- PLATEAU公式 `datacatalog/3dtiles/{cityCode}-bldg-lod1-latest/tileset.json` を使用する。MVT属性から高さを推測した建物は作らない。
- CesiumJS 1.117.0を都市ビューを開いた時だけ読み込み、建物は3D Tilesとして視野に応じて取得する。利用者のAPIキーは不要。配信APIは試験提供であり対象地域・データ年度に依存する。
- 土地の起伏はまだ組み合わせない。単色の楕円体地面とLOD1建物形状を表示し、都市側の照明は固定する。既存の地形・地質・断面・立体視設定は都市側へ移さない。
- PCは最大1180×820の専用画面、縦画面は画面全体、横画面はヘッダー等を縮めて建物の領域を確保する。地形側の狭い操作バーは横スクロールでボタンを収める。
- 初期画面の山岳地点で対象モデルがない場合も、画面内の「東京で試す」で東京駅周辺を選べる。
- 地形拡大表示の背景inertと干渉しないようdialogをmainの外へ置く。閉じる・Escapeで通信を中断し、Cesiumの描画資源を破棄する。古い通信結果を採用しない。
- 404、通信失敗、描画失敗、60秒の読み込み待機を表示する。建物が実際に描画対象になったtileVisibleイベントを受けて操作案内へ切り替える。

公式仕様： https://docs.plateauview.mlit.go.jp/quickstart/

検証は `VERIFICATION.md` を参照。テスト用の合成建物を実際のCesiumで描画する確認と、公式配信データの実動作を区別する。
