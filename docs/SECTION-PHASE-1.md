# 地形断面図 第1段階 — 0.12.0

既存のDEM・三角形メッシュ、四つの表示モード、独立した表示設定パネルを調査したうえで、2点間の断面のみを追加する。計測ツール・飛行・保存・共有は追加しない。

## 操作と配置

設定パネルの「地形断面図」→「2点を選ぶ」でパネルを閉じ、地形上の短いタップ／左クリックでA、Bを選ぶ。ドラッグ、Shift・中ボタン、2本指は従来の視点操作を維持する。途中で2本指になった操作、6pxを超えた移動、pointercancel、lostpointercaptureは点選択にならない。キーボードはEnterで表示領域中央（左右表示では左画像中央）を選び、矢印で視点を調整して2点目を指定する。Escape・「中止」で選択をやめる。選択中だけ既存の上部操作バーを案内と「中止」に切り替え、地形の上に案内を置かない。

2点を選ぶと既存パネルにグラフを表示する。「選び直す」「消す」を用意する。PCは従来の横パネル、縦画面は下のパネル、拡大時は既存の開閉可能なパネルを使用。横画面の3D表示面積を恒常的に縮めない。地形上には小さなA・Bだけを投影し、地形を横切る大きな線は描かない。マークは画面上の補助表示で、地形との深度遮蔽は行わない。視点により裏側の地点のマークが見える場合がある。

## 計算と既存構造への影響

- 断面のUIと計算モジュールはボタンの初回操作時に動的import。標高・画像の追加取得はない。
- rendererはGPUへ送るフィット済み頂点と三角形indicesのみを参照保持する。描画と点選択で同じカメラ生成を使う。画面三角形の最近深度とclip Wで補正した重みから正確なメッシュ交点を求める。欠損三角形は選べない。
- 平行法・交差法は実際の左右カメラとviewportを使用。赤シアンでは重なった画像の中央カメラを選択基準にするため、強い立体感では色別輪郭と多少ずれる場合がある。
- 点はグリッド内の正規化座標で保持。高さ強調・カメラ・表示モード・画面回転で保持。画質変更で新DEMに再補間。同じ緯度経度でも縮尺が変わった場合、地点変更の成功時はクリア。読み込み失敗で現在の地形・断面を消さない。
- graphは三角形の対角線と一致した実標高mの補間。横軸はグリッド間隔から求める水平距離kmで、地表沿い距離・測量値ではない。セル境界と対角線の交差位置も採取し、区間中点にデータがなければ線を接続しない。補完DEMの精度はその元データによる。
- 選択時だけ全頂点を投影し三角形を走査する。毎フレームでは2点のマークのみ更新。最高精細では一時的な配列とメッシュ参照保持分のメモリが増える。実機性能は別途確認が必要。
