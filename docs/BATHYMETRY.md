# 海底地形の表示・操作ガイド

## 使い方

1. 3D表示の「設定を開く」を押します。
2. 「海底地形を表示」をONにします。初回は、現在の表示範囲に必要なGMRT水深データを読み込みます。
3. 水深に応じた青色の地形と、その下の水深凡例を確認します。浅い水色から濃い青へ変わり、凡例には水深（標高が負の値であること）を示します。照明による陰影が加わるため、地形の色は凡例の基準色より暗く見えることがあります。
4. 名所ガイドの海底スポット、または設定の「青ヶ島と周囲の海底を見る」「八丈島〜青ヶ島の海底を広域表示」「八丈島を近くで見る」から、観察範囲を選べます。
5. もう一度OFFにすると、海底だけを隠します。海底OFFの間は水深データを取得しません。

海底をONにしても、陸地の標高・形・カメラ視点は保たれます。水深の色尺度は地点や範囲により異なるので、名所どうしを比べるときは凡例の上限も確認してください。断面図と等高線は、海底を負の標高として扱います。

## 対応地点とデータの選択

海底対応スポットは「地形・地質の名所を探す」の分類から探せます。現在は日本周辺30の観察スポットを登録し、必要範囲に重なる地域データだけを読み込みます。島の近景では喜界島・青ヶ島・八丈島・諏訪之瀬島・口永良部島・西之島・与那国島の狭域格子を優先し、広域表示やその外側では地域の広域格子を利用します。狭域データが取得できないときも、利用可能な広域データへ切り替えて表示を続けます。

地域データは初期起動時に一括取得しません。読み込んだグリッドは合計8MiB・最大8地域のメモリキャッシュで再利用します。海底表示をOFFにしているときは水深データへの通信は発生しません。

## データの読み方と限界

海底データはGMRT公式GridServerから取得して加工した数値格子です。狭域格子の返却間隔はおよそ51〜56m、地域によっては数百〜数千mです。格子間隔は測深精度や測深点間隔ではありません。高解像度資料の寄与が確認できない範囲もあります。格子を細かく表示しても、元の測深情報の精度が上がるわけではありません。

陸地の標高には国土地理院DEMを優先し、海底の水深にはGMRTを使います。海岸付近で両データの差により接続段差が見える場合があります。欠測域を架空の海底地形で埋めることはしません。水深・測深精度は航行、安全、測量、災害判断には使わないでください。

GMRTの利用条件は[CC BY 4.0](https://www.gmrt.org/about/terms_of_use.php)です。出典・取得範囲・変換・各地域の格子情報・検証結果は[広域海底データの記録](BATHYMETRY_PHASE2.md)と[`data/bathymetry`](../data/bathymetry/)のmanifestを参照してください。

## iPhone Safariでの確認

1. 公開アプリを開いて、3Dビューの設定を開きます。
2. 「青ヶ島と周囲の海底を見る」を押し、青い海底と水深凡例が表示されるまで待ちます。
3. 「海底地形を表示」をOFF→ONにし、陸地と視点がそのままであることを確認します。
4. 名所ガイドで別の島、または「日本海溝」などの広域海域を選び、場所ごとに凡例の上限と海底の形が変わることを確認します。
5. 海底ONの状態で等高線・断面図・立体視・共有を試し、共有リンクを開き直して海底表示が復元することを確認します。
6. 海底をOFFにして、凡例が隠れ、陸地表示へ戻ることを確認します。

Chromiumのスマートフォン相当画面での確認と、iPhone実機Safariでの確認は別です。実機Safariの検証結果は利用者側で確認してください。
