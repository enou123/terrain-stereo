# 観察補助・第1段階（0.7.0）

## 調査と設計

地形は東＋X・標高＋Y・南＋Z。OrbitControlsはカメラを回転し、rendererは同じ方向のカメラで通常・平行・交差・赤シアンを描画する。既存のイベント駆動描画・画面サイズ変更処理を利用し、取得・メッシュ・立体視投影・UI配置を変更しない。

- ビュー下隅に64px、スマートフォンでは56pxのコンパスを置く。N/E/S/Wの地理的ベクトルをカメラの右・上の軸に射影し、回転と傾きに追従。北は矢印と色で識別。低い角度でも文字が軸に重ならないよう、ラベルだけを軸の先から少し離す。
- 平行法・交差法では、各眼画像の同じ基準位置（横50%、上部82〜88px）に8pxの＋を自動表示。通常3D・赤シアンでは非表示。コンパスも各眼画像の同じ位置に同じ向きで複製し、融合時の不一致を減らす。奇数の描画幅も含めrendererの実ビューポート分割に合わせる。
- DOM/SVGオーバーレイは入力を遮らず、描画更新時だけ更新。WebGLパスの追加、常時アニメーション、新たな取得・依存・設定項目は不要。
- コンパスとマークは画面上の観察補助で、地形上の特定地点を示すものではない。操作ガイドに読み方を記載。

## 今回の範囲

方位表示・立体視位置合わせマークのみ。等高線・画像テクスチャ・地質・断面・飛行・世界・都市3D・画像保存には触れない。0.6.0の配置、拡大、設定保持と既存地図・画質・高さ・全表示モードを回帰確認する。
