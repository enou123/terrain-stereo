# 地形表面の切替：第1段階（0.9.0）

## 今回の範囲

標高の色（初期値・従来の表示）と陰影のみを選ぶ設定を1つ追加する。陰影のみは中立色の表面に既存の斜面照明を適用する。等高線と4表示モードは併用可能。航空写真、地質図、画像テクスチャ、太陽位置変更、断面等は追加しない。

## 既存構造への影響

Rendererが表面の設定を保持し、同じフラグメントシェーダー内でuniformにより頂点の標高色と中立色を切り替える。陰影の計算、等高線、赤シアンの白黒変換・チャンネル分離はその後に従来どおり適用する。データ取得・メッシュ生成・頂点属性・描画回数は増やさない。

PC・iPhone相当の縦・横は既存の設定パネルに標準selectを置く。横画面の3D優先、開閉・拡大の構造を変えない。陰影のみと赤シアンのときは標高色の凡例を隠し、説明文も選択に合わせる。

切替は描画だけを要求し、視点・地点・画質・高さ・等高線を変更しない。地点・画質変更で新しいメッシュを設定しても表面の設定を保持する。視点リセットも表面を変えない。等高線拡張非対応の端末でも表面切替を利用できる。

## 検証

既存Nodeテスト。Chromiumの既知形状による画素確認では陰影の中立色・標高色からの独立・斜面への応答・全モードの復帰・両表面の等高線と欠損部分を検証する。実DEMの8画面サイズで表面切替と状態保持、マウス・タッチ・画面回転・設定開閉・拡大・既存操作を確認する。沿岸部の最高精細404補完も陰影のみ・等高線併用で確認する。スクリーンショットを目視確認する。Safari実機・物理GPU性能は未確認として記録する。
