# 名所の観察機能 第2段階 — 0.28.0

## 操作と構成

名所は17地点のまま。代表6名所に10スポットを追加した。名所を「この場所を見る」で開いた後、解説内の「見どころへ近づく」で選び、「この見どころを見る」を押す。選択するだけでは視点・DEM・設定は変わらない。「名所全体へ戻る」は現在の観察方法（地形／地質）で全体のおすすめを明示的に適用する。「おすすめ設定に戻す」は現在の見どころのおすすめに戻す。

スポットは独立した js/landmark-spots.js に管理。中心・DEMズーム・画質・高さ・カメラ・注目範囲・短い解説・限界・資料を持つ。全体表示と同じ visitLandmark とDEM・画像取得を再利用し、場所と縮尺が変われば必要なDEMを取得する。同じDEMは再取得しない。既存の取得キャッシュ・4並列の上限を維持する。

DEMは従来の整数ズーム上限14、表示幅384画素。見どころは高精細を推奨（385×385）。ズーム14で約8mのサンプル間隔になるが、測量の解像度自体が増えるわけではない。親タイルへの補完時は既存の画質案内で通知する。カメラは実メッシュの注目範囲を囲み、注視点・俯角・距離を調整する。海の欠損部分を除き、カメラは有効地形の最高点より上に置く。小さな丸山などは約3kmのDEMの中で近づき、DEMの外を架空の地形で埋めない。

「地形を楽しむ／地質を学ぶ」の切り替えは見どころID・範囲・カメラ・高さ・画質・等高線間隔を保持し、表面と解説のみを変える。ツアーは見どころIDと選択中の項目、等高線間隔も保存・復元する。共有URLでは ci に等高線間隔を保存。古いリンクや無効な間隔は100mとし、起動時に名所のおすすめで共有設定を上書きしない。

スポットの取得失敗時は直前の場所・カメラ・設定・ガイドを保持して通知し、同じボタンで再試行できる。

## 等高線間隔

10・20・50・100・200mを選択。通常起動は従来の100m・OFF。名所の明示的な訪問時に推奨間隔を設定するが、線のONは利用者が選ぶ。低い島は10m、秋吉台全体は20m、富士山・黒部全体は200m。見どころは上表を参照。

GPUシェーダーは実標高を間隔で割って線を描き、高さ強調やメッシュの画面への縮小によって標高は変えない。密集して解像できない線は画面微分で薄くする。等高線間隔の変更はDEM取得やメッシュの再生成をしない。平坦な面全体を線の色で塗らず、欠損地形に線を描かない。未対応端末ではチェックと間隔選択を無効にし、通常3Dを維持する。

## 産総研の実データ取得の調査

現行の公開仕様 [シームレス地質図V2 Web API 1.3.1](https://gbank.gsj.jp/seamless/v2/api/1.3.1/) と照合した。タイルURLの順は z/y/x、ズーム上限13、type=original。凡例のboxは南,西,北,東、pointは緯度,経度。矩形では配列、地点では単一オブジェクトという応答形式も実装と一致する。通信先・APIバージョンを変更せず、第三者プロキシ・新サービスを追加しない。

開発環境の許可ホストは cyberjapandata.gsi.go.jp を含むが gbank.gsj.jp を含まない。現在のネットワークポリシーは restricted/enforced。公式のサンプルタイルと秋吉台の地点凡例を通常のHTTPS通信で試すと、どちらも `Tunnel connection failed: 403 Forbidden`。HTTPSトンネル確立の段階で拒否され、産総研にHTTPリクエストを送る前の失敗である。一般の利用者に産総研が403を返している証拠ではない。許可の迂回は行っていない。

公式APIは地質図のない場所に透明PNGを返す。既存のシェーダーがその透明度を無視して黒く描画する問題を修正した。部分欠損は元の地形を残し、範囲全体が透明なら「この範囲には地質図データがありません」と通知して標高色へ戻す。この処理は明示したテスト用透明PNGで検証し、実地質図の成功表示とは区別する。

開発環境からの実地質タイル・実凡例成功、およびiPhone実機Safariは未確認。地質図は20万分の1の概略で、近づいても小さな岩石・地下構造を細かく再現できるわけではない。

## iPhone Safariで確認する手順

1. 公開アプリを再読み込みし、「地形・地質の名所を探す」で秋吉台を選び「この場所を見る」。
2. 3Dを回転・ピンチで調整し、解説の「地質を学ぶ」。実際の色分けが出て、視点・範囲・高さが保たれるか確認。
3. 「地質の凡例・地点情報を見る」を押し、岩石と年代の一覧が出るか確認。地形上の色の付いた場所をタップし、その地点の凡例が強調されるか確認。
4. 「地形を楽しむ」へ戻り、見どころで「長者ヶ森西側のドリーネ群」を選んで移動。等高線をON、10mと100mを比較。縦横回転し、ボタン・説明が操作できるか確認。
5. 見どころで再び地質を学び、元の見どころが維持されることを確認。「名所全体へ戻る」で全体へ戻る。
6. 南大東島で西側の幕へ移動し、10mの線と高低差を確認。共有リンクを開き直し、場所・視点・等高線間隔が保持されるか確認。
7. 地質図や凡例が失敗する場合は画面のエラー文を確認。同じSafariの別タブで [公式の秋吉台地点凡例](https://gbank.gsj.jp/seamless/v2/api/1.3.1/legend.json?point=34.25,131.31) を開く。そこでも開けない場合と、公式JSONは開くがアプリで失敗する場合を分けて、エラー文・名所・回線種別を報告してもらう。
