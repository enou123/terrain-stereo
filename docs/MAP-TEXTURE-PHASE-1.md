# 地図テクスチャの第1段階（0.10.0）

地形表面の既存selectに「地理院地図」を追加する。標高色が初期値。PC・縦・横の配置は変えず、横画面の3D優先を維持する。航空写真・地質・太陽位置等は追加しない。

画像取得と合成は新規texture.jsに分離。DEMと同じ丸めた中心と384ピクセル範囲を使用し、DEM画質から独立した地図ズーム（地形ズーム＋1、上限14）で取得。最大16タイル・並列4・1024平方のatlas1枚。選択時だけ取得し、範囲キーで現在の1枚を再利用。変更時にAbortControllerでキャンセルし、要求番号で古い応答を除外。25秒タイムアウト、失敗時は標高色に戻して地図画像のみ再試行。成功した新しいDEMに合わせて古い地点のGPUテクスチャを解放し、誤った地図を重ねない。

Rendererに格子UVとsamplerを追加。北が画像上・東が右、地形Xが東・Zが南に一致。既存の欠損三角形省略と立体視投影を使用し、地図にも控えめな陰影・任意の100m等高線を適用。赤シアンは白黒変換後に左右チャンネル合成。高さ変更・メッシュ差し替え後もUVが同じ範囲を覆う。画像の文字・印刷済み等高線は固定で、拡大・回転時に傾く。これは今段階の仕様。

検証は既存自動・UI・沿岸補完・等高線GPUの回帰、新規の座標整合・取得並列上限・異常・キャンセル、既知四隅の色による向き・欠損・GPU解放、実地図8サイズ・全表示モード・縦横変更・高精細・地点変更・再試行。スクリーンショットでPC・縦・横を目視確認する。Safari実機、実端末性能、公開URL確認は区別して記録する。
