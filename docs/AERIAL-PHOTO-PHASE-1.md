# 航空写真 第1段階

既存の地形表面選択に航空写真だけを追加する。国土地理院 seamlessphoto JPEGタイルを選択時に取得し、既存のDEMと同じ範囲・UV・1024平方atlas、最大16枚・並列4で描画する。撮影時期は地域で異なる旨を表示する。

画像取得をtexture.jsに保ち、種類を範囲キーに含める。CPUのキャッシュとGPU画像はそれぞれ1枚だけ保持する。描画側も画像の種類を記録し、別種類の古い画像を表示しない。切替や地点変更は中止・要求番号で競合を防ぐ。404・通信失敗・タイムアウト時には標高色で操作を継続し画像だけ再試行できる。画像欠落を架空の写真で埋めない。

従来の地図・陰影・標高色、等高線、全立体視モード、視点・画質・高さ・縦横レイアウトを維持する。赤シアンでは写真も無彩色にする。新たな描画パスや依存ライブラリは不要。地質・断面・飛行等は今回の対象外。
