# コンパスから北向きの真上表示（0.31.0）

3D画面のコンパスをクリック／タップすると、現在読み込んでいる範囲を次の視点で表示します。

- 真上（俯角90°）。
- 北が上。
- 読込範囲の中心が画面中央。
- 地形全体が収まる距離。

場所やDEMの範囲は変更せず、追加の標高通信も行いません。表面表示・等高線・高さ倍率・画質・立体視モードを維持します。遊覧飛行は停止します。機能紹介ツアーの実演中と地形の読込中は視点を上書きしません。

コンパスはネイティブのボタンで、Tab→Enter／Spaceでも使えます。画面に表示している各立体視画像のコンパスを押せます。真上にした後も回転・移動・ズームが可能です。「範囲・遊覧」の移動・縮尺の基準も真上の視点に更新し、直前の未反映の移動量を残しません。

## 描画

真上では通常のカメラ上方向ベクトルと視線が平行になるため、北向きの上方向ベクトルを使って安定した行列を計算します。真上から回転する操作ではカメラの方位に対応した上方向を渡し、通常の回転操作を維持しています。立体視の左右方向にも同じ処理を適用しています。共有リンクの俯角上限も90°に拡張し、リンクへ保存した真上視点を復元できます。

## 検証

`npm test`：14テストファイルが成功。真上の方位、行列の有限性、左右カメラの中央配置、共有リンクの俯角丸めを確認。

`python tests/compass.browser.py`：Chromium＋SwiftShader／WebGLで、国土地理院の実DEM（取得済みキャッシュを含む）を使用。1440×900・390×844・844×390でクリック／タップ、90°の俯角、北向き、中心点の投影、地形の画面内への収まり、追加DEM通信がないこと、キーボード操作、通常の回転、遊覧停止を確認。PCは通常3D・平行法・交差法・赤シアンの4モードを確認。JavaScript・WebGLエラーなし。

`RANGE_VIEWPORTS=1440x900 python tests/view-range.browser.py`：範囲移動・縮尺反映・失敗時の復帰・遊覧飛行を回帰確認。

背景地図は取得済み実タイルのみを使用し、未取得の背景地図は404として処理しています。地質図は今回の検証対象ではありません。iPhone相当のChromiumによる確認であり、iPhone実機Safariでは未確認です。
