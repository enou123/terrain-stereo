# 日本の地形・地質名所ガイド — 第1段階

この文書は0.27.0の設計記録です。見どころ観察・可変等高線の最新仕様は[第2段階](OBSERVATION_STAGE2.md)を参照してください。

## 構成と操作

17地点の資料・設定は js/landmarks.js、選択と解説のUIは js/landmark-guide.js、実メッシュの初期カメラ調整は js/landmark-camera.js に分離。既存のDEM、画像取得、地質凡例、地点情報、カメラを再利用し、ライブラリ・サービス・APIキーを追加しない。

種類と地域は組み合わせて絞り込める。「地図で自由に選択」と「ここを立体表示」は従来の自由操作を維持。「この場所を見る」はおすすめ範囲・高さ・表面・画質・視点を一度に適用。「地形を楽しむ／地質を学ぶ」の切り替えは表面と解説だけを変更し、現在の範囲・視点・高さ・画質・等高線を保持する。「おすすめ設定に戻す」は明示的に設定を再適用する。

共有URLと通常の起動ではおすすめを自動適用しない。手動操作を監視しておすすめへ戻す処理もない。機能紹介ツアーは開始前の名所ガイド・フィルターも保存し、終了時に復元する。解説は画面の通常の流れに配置し、3Dキャンバスへ重ねない。拡大表示中はガイドを隠し、元の表示へ戻すと再表示する。

## 表示中心と範囲の決め方

緯度・経度はWGS84の観察中心。気象庁の山頂座標、自治体の位置情報、地理院地図の地名・海岸・谷の配置を基に設定。中心は山頂の精密測量値ではない。気象庁の山頂と中心が異なる島は、島全体が囲める位置に調整した。各地点の coordinateNote と references を参照。coverage は観察したい概略範囲であり、行政界や地質境界ではない。

表示距離は既存の terrainExtent（384画素のWeb Mercator範囲×中心緯度の縮尺）から算出。DEMのズームは整数6〜14、地図のズームはDEMズーム−1。画質によって範囲は変えない。coverage の四隅が丸めたDEM原点から±192画素の中に入ることをテストする。

## カメラと描画負荷

おすすめ方向・俯角を使い、取得したメッシュの有効三角形の頂点から実際の表示範囲を計算。海の欠測頂点は除外し、実地形の中央を注視する。透視投影と既存レンダラーの縦画面補正を考慮して、地形が余白を残して収まる距離を決める。初期カメラは地形の最高点より高く保つ。おすすめ全地点は標準画質を基本にし、利用者が必要に応じて高精細へ変更する。小さな大室山は狭い範囲、カルデラ全体を見る阿蘇は広い範囲を使う。低い台地・サンゴ礁の島は陰影と高さ強調で起伏を見つけやすくする。光は南東145度・高度50度をおすすめの初期値とし、陰で手前側の地形が見えなくなることを避ける。地質モードへ切り替えるときは利用者の光の設定も維持する。高さの実比率と強調の違いは既存の設定欄で確認できる。

## 解説・資料・データの限界

文章は独自に要約し、特徴・成り立ち・観察ポイント・資料リンクを分ける。岩石名・年代は一般的な地域説明と、現在の地質図の凡例で確認する情報を分ける。地質図の色境界を断層の正確な位置と同一視しない。地下構造・海底地形・小さなドリーネ・細かな火口壁を架空の形で補わない。薩摩硫黄島では陸上のカルデラ縁の島を示し、鬼界カルデラの海底全体を再現したとは説明しない。喜界島・南大東島の低い段差は100m等高線に現れない場合がある。

地質図に失敗した場合は既存の標高色へ戻る実装を使い、失敗をガイドにも明記する。テスト画像を実際の地質データとして配信しない。ブラウザ検証は実GSI DEM・標準地図と、GSJ実通信／テスト画像の検証を別に記録する。ChromiumのタッチエミュレーションはiPhone実機Safari検証とは区別する。
