# 遊覧飛行の選び方

3Dビュー上部の「範囲・遊覧」→「遊覧飛行を選ぶ」を開きます。初期選択は、画面中央を軸に水平周回するモードです。飛行モードと速度を選び、周回数のボタンを押すとすぐに開始します。

## 飛行モード

- **画面中央を軸に水平周回（標準）**：開始時に画面中央で見ている地点を軸にします。開始時の俯角とカメラ距離を保ち、カメラがその地点を見ながら水平に回ります。Shift＋ドラッグや2本指操作で地形を移動した後なら、移動後の画面中央が周回軸になります。真上から見る場合は、地形が中央を軸に回転して見えます。
- **地形を見渡す遊覧**：カメラの注視位置を地形上で少し動かしながら周囲を巡ります。高さ・俯角・距離も変化するため、地形をさまざまな角度から眺められます。

遊覧中もドラッグ・2本指操作・ホイール・キーボードで回転・移動・ズームできます。自動周回を止めるときは、3D画面上部の遊覧ボタンを押します。有限周回は設定した周回数で自動停止します。

## 周回数と速度

- 周回数：1・2・3・5・10周、または連続
- 速度：0.5〜2.0倍、0.1倍刻み
- 速度1.0倍：1周約32秒

周回数と速度は別々に選べます。たとえば速度を0.7倍にして2周、または速度1.5倍で連続周回できます。連続飛行は上部の停止ボタンを押すまで続きます。

遊覧開始・終了で、表示地点や読み込み範囲、地形表面、画質は変更しません。標準モードでは開始時の画面中央の注視点・俯角・距離を保ちます。手動操作をした場合は、その操作を反映した状態から周回を続けます。

## 動作確認

`npm test` は周回姿勢・停止条件・手動操作後の再基準化を確認します。`python tests/ui.browser.py` はPCとスマートフォン相当の縦横画面で、両方の飛行モード、遊覧中の回転・移動・ズーム、上部ボタンでの停止を確認します。`python tests/tour.browser.py` は機能紹介ツアー内の標準モードを確認します。iPhone実機Safariは別途確認が必要です。
