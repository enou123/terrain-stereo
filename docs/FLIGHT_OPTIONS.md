# 遊覧飛行の種類・周回数・速度（0.33.0）

「範囲・遊覧」内の「遊覧飛行を選ぶ」を開き、飛行モードと速度を選び、周回数のボタンを押すと、その設定ですぐに開始します。

- **従来の遊覧飛行**：これまでの target の動き、高さ・俯角・距離の変化を残しています。
- **画面中央を軸に水平周回**：開始時点の `controls.target` を3D上の回転軸として固定します。事前にShift＋ドラッグや2本指操作でパンした場合も、パン後の画面中央が軸です。カメラの俯角・距離（したがって軸からの高度と水平半径）も開始時の値に固定し、yawだけを360°ずつ変えます。
- 周回数は1・2・3・5・10周、または連続。
- 速度は0.5〜2.0倍を0.1刻みで調整。標準速度は1周約32秒で、周回数とは独立しています。

遊覧中もドラッグ・2本指操作・ホイール・キーボードで回転、移動、ズームできます。操作した視点を保ったまま自動周回を続けます。飛行を手動で止めるときは上部の「遊覧中 · 停止」ボタンを押します。有限周回は指定した周回数で自動停止します。遊覧の開始・終了で地形の場所、範囲、地形表面、画質などは変更しません。機能紹介ツアー内の遊覧は従来モードのままです。

真上（俯角90°）では、固定高度・固定俯角の条件上、カメラの水平半径は0です。その位置のまま方位が回り、地形が画面中央を軸に回転して見えます。水平に位置が巡る軌道は、真上以外の俯角で使用できます。

## 確認項目

`npm test` では画面中央のtargetを変えずに周回する姿勢関数と、手動の回転・パン・ズーム後もその視点を保って周回を続ける再基準化処理を検証。`python tests/ui.browser.py` でPC・スマホ縦横の両飛行モード中に回転・移動・ズームでき、上部ボタンで停止できることを確認。`python tests/tour.browser.py` で既存の機能紹介ツアー内の遊覧飛行を確認。

周回軌道の確認には実際の地形データを使用します。iPhone実機Safariは別途確認が必要です。
